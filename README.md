# automato-finito-deterministico-e-linguagem
Projeto: Construção e Implementação de um Autômato Finito Determinístico (AFD)

Este projeto é a segunda fase do trabalho de Linguagens Formais e Autômatos e tem como objetivo desenvolver um Autômato Finito Determinístico (AFD) que reconhece a linguagem definida na Fase 1.

Objetivos

Modelagem do AFD: Formalização do autômato como uma 5-tupla
M = (Q, Σ, δ, q₀, F), definindo:

Conjunto de estados (Q)

Alfabeto (Σ)

Função de transição (δ)

Estado inicial (q₀)

Conjunto de estados finais (F)

Diagrama de Transição: Representação visual do autômato para facilitar a compreensão das transições.

Implementação em Python: Desenvolvimento de um programa capaz de:

Ler uma cadeia de entrada.

Simular o funcionamento do autômato.

Informar se a cadeia é aceita ou rejeitada.

Testes

O funcionamento do programa é validado utilizando todas as cadeias de teste definidas na Fase 1, garantindo que o autômato reconheça corretamente a linguagem proposta.
